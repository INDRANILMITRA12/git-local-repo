Git Commands
===========###########====================
1 - git --version --> To check which version of git is already installed

2 - git status --> To check the staus of the repo

3 - git init --> To create a git folder. Here we are creating the git folder from local to github.

4 - git clone <https link> --> To clone a existing git repo to local it is simillar to git init but here we are inializing from 
github to local.

5 - git add <filename> --> To add the file to the stagging area

6 - git commit -m "commit message" --> To commmit the changes 

7 - git remote add origin <https link> --> to add the remote repo named origin where we will push

8 - git push origin main --> Here origin is the name of the remote repo in git and main is the branch name.

9 - git push -u origin main --> It helps in settingh the upstream so that from the next time whenever we will push it
will pushed to the main branch.

10 - git pull --> To load the contents form the git hub to local after the git inializing is done.

11 - git log --> To get the git commit logs

12 - git log --> oneline -> to get the commit message in one line

13 - git statsh --> To temporarly store a stagging file switchng branch

14 - git stash save "message" --> To stash with message

15 - git stash apply --> To bring the top stash file to the branch

16 - git stash apply stash@{number} --> to bring the specific stash number

17 - git stash pop --> TO apply the stash and clear it 

18 - git stash apply stash@{number}  <branch name> --> To applty a specific stash to a specific branch

19 - git stash clear --> TO clear the stash

20 - git reset --hard <hashid> --> To reset the previous version 

21 - git reset --head@{1} -->

22 - git reflog -->To get the details of all the log
